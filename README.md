# Vehicle Transfer Management System (Sample)

This repository is a **sanitized public version** of a real-world system
developed for managing vehicle transfer operations.

## Purpose
This project is shared for **technical and educational purposes only**,
demonstrating software engineering practices, system architecture,
and cloud integration.

## Key Features
- Vehicle pickup and delivery workflows
- Photo capture and storage (Azure Blob Storage)
- Digital signature capture
- PDF report generation
- Email notification integration
- SQL Server persistence

## Technologies
- ASP.NET MVC (.NET / C#)
- SQL Server
- Azure Blob Storage
- Azure Email Communication Services

## Security Notice
All secrets, credentials, and production configurations were removed.
This repository does **not** represent a deployable production environment.
